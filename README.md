# Curated Market Data, Bhavcopy & Metals GitHub Directory

## 1. Indian Stock Market APIs & MCP Servers
- [BennyThadikaran/NseIndiaApi](https://github.com/BennyThadikaran/NseIndiaApi) — Unofficial Python API for NSE India quotes, indices, corporate actions & F&O
- [BennyThadikaran/BseIndiaApi](https://github.com/BennyThadikaran/BseIndiaApi) — Unofficial Python API for BSE India announcements, corporate actions & data
- [Tapetide-hq/nse-bse-indian-stock-market-data-mcp](https://github.com/Tapetide-hq/nse-bse-indian-stock-market-data-mcp) — MCP server connecting NSE/BSE market data & screening tools
- [0xramm/Indian-Stock-Market-API](https://github.com/0xramm/Indian-Stock-Market-API) — Free REST API wrapper for NSE and BSE data
- [maanavshah/stock-market-india](https://github.com/maanavshah/stock-market-india) — REST/Node API wrapper for NSE and BSE data

## 2. Historical NSE/BSE Bhavcopy & Index Archives
- [BennyThadikaran/eod2](https://github.com/BennyThadikaran/eod2) — Automated Python EOD downloader for NSE equity, index & delivery data (with corporate action adjustments)
- [jugaad-py/jugaad-data](https://github.com/jugaad-py/jugaad-data) — Python library for NSE live/historical stock, index & derivatives bhavcopy
- [RuchiTanmay/nselib](https://github.com/RuchiTanmay/nselib) — Official PyPI NSE library for bhavcopy, delivery data, bulk/block deals & option chain
- [NikhilSuthar/indian-market-data](https://github.com/NikhilSuthar/indian-market-data) — Python packages for 91 NSE datasets, 55+ BSE indices & 28 MCX commodities
- [Arickaji/GetBhavCopy](https://github.com/Arickaji/GetBhavCopy) — Automated NSE equity & index bhavcopy downloader
- [girishg4t/bhavCopy-downloader](https://github.com/girishg4t/bhavCopy-downloader) — NSE & BSE bhavcopy and derivatives downloader
- [technovusin/nifty50-historical-data](https://github.com/technovusin/nifty50-historical-data) — Nifty 50 1-minute & 15-second historical OHLC archives
- [sandeepkapri/BankNifty-Data](https://github.com/sandeepkapri/BankNifty-Data) — Bank Nifty historical intraday & EOD archive
- [aditya-jha/nse-historical-membership](https://github.com/aditya-jha/nse-historical-membership) — Historical NSE index inclusions & exclusions archive
- [pkjmesra/PKNSETools](https://github.com/pkjmesra/PKNSETools) — Nifty 50, Nifty Next 50 & Nifty 500 constituent and OHLCV toolkit
- [marketcalls/ExpiryTrack](https://github.com/marketcalls/ExpiryTrack) — Expired F&O contract data downloader
- [NSEDownload/NSEDownload](https://github.com/NSEDownload/NSEDownload) — Historical NSE stocks & indices CSV downloader (archive)
- [vsjha18/nsetools](https://github.com/vsjha18/nsetools) — Legacy Python NSE quote library (archive)
- [kalilurrahman/NIFTY_50_STOCK_DATA](https://github.com/kalilurrahman/NIFTY_50_STOCK_DATA) — Static Nifty 50 constituent CSV archive
- [ShabbirHasan1/NSE-Data](https://github.com/ShabbirHasan1/NSE-Data) — Static NSE intraday archive
- [Sdaas/nifty-analysis](https://github.com/Sdaas/nifty-analysis) — Static Nifty Next 50 & 500 analysis notebooks
